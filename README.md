# Outlier AI Recreation (Next.js + Tailwind CSS - White Design)

An accurate, production-ready visual and interactive recreation of the [Outlier.ai](https://outlier.ai/) website in a **crisp, modern white theme**, built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

## 🛠 Running the Next.js Application

### 1. Install dependencies
```bash
npm install
```

### 2. Start the local development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎨 White Theme Design Highlights

1. **Light Visual Language**:
   - Clean white canvas (`#FFFFFF`) with subtle off-white section contrasts (`#F8FAFC`).
   - Deep slate typography (`#0F172A`) with high legibility and refined tracking.
   - Refined 1px light borders (`#E2E8F0`, `#CBD5E1`) and soft multi-layered shadows.
   - Polished solid dark buttons (`#0F172A` / `#000000`) for primary actions.

2. **Replicated Sections**:
   - **Sticky Frosted Glass Navbar**: Logo + "by Scale AI" mark, desktop navigation, Log In / Apply buttons, and mobile drawer.
   - **Hero Section**: Live openings pill, bold display headline, trust badges, and an **interactive split-screen RLHF evaluation console** comparing Model A vs. Model B with dark-slate code blocks.
   - **Metrics & Ecosystem**: $150M+ total paid, 250k+ contributors, 100+ countries, with AI lab partner tags.
   - **Why Outlier (Bento Grid)**: 4-card value proposition with schedule autonomy, weekly payouts, and tier progression.
   - **Domain Specializations**: Interactive category filter across Coding, Mathematics & STEM, Writing & Humanities, Languages, and Life Sciences with hourly rates.
   - **Interactive Model Simulator**: Live multi-domain RLHF sandbox letting users evaluate model accuracy, review rubrics, and test scoring calibration.
   - **How It Works (3-Step Timeline)**: Visual numbered journey from application to weekly payouts.
   - **Dynamic Earnings Calculator**: Interactive hours-per-week slider and discipline selector.
   - **Contributor Testimonials**: Real-world contributor quotes, star ratings, and specialization tags.
   - **FAQ Accordion**: Clean white expandable accordion for common questions.
   - **Pre-Footer CTA Banner**: High-contrast dark-slate pre-footer conversion section.
   - **Footer**: Brand links, domains, legal policies, system status, and social channels.
   - **Interactive Overlays**: 3-step Contributor Application Modal, Sign In Modal, and Cookie Consent notice.
